## Checked and not a defect

- **"1 provider error" on Data sources:** a transient FRED fetch failure during the start-up catch-up. It cleared on retry: 17 fresh, 1 stale, 0 errors.
- **India CPI shown as stale:** the source (OECD MEI via FRED) has no observation after Mar 2025. ATLAS labels it stale, which is correct.
- **No key values in any tracked file, log, report, artifact or the built frontend:** checked by value matching, with counts only and no values printed.
