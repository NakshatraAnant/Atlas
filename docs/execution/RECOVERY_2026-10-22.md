## 3. Videos produced (session 7)

Pipeline: `npm run video:render [id…]` → offline narration (Windows speech, Microsoft Zira) + canvas animation encoded in headless Microsoft Edge (WebCodecs VP9 + Opus, muxed with `webm-muxer`) → `apps/api/media/academy-videos/<id>.{webm,png,vtt,txt}` + `apps/api/src/modules/academy/videos.generated.json`. Every number in the scripts is checked against `packages/shared` before rendering (`checkScripts`), and the script numbers were also re-derived by hand in this session. `npm run video:verify` decodes each file in Edge over HTTP with byte ranges, checks duration and size, plays it muted, confirms decoded video and audio, loads the captions and saves frames for visual review.
